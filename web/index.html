aarch64_emu_cpp

An AArch64 Linux executable, interpreted instruction by instruction, in this tab. The emulator is C++17 compiled to WebAssembly; the guest is real ARM64 machine code. Nothing is uploaded.

Or run a real macOS program. A stock arm64 Mach-O against Apple's own libSystem, libobjc, libxpc, libdispatch and libcorecrypto — 46 libraries extracted from a Mac's dyld shared cache. Apple's dyld cannot be shipped, so the emulator does its job: mapping, chained fixups, symbol binding, initializers in dyld's order, and the exit that flushes stdio. 26 MB, fetched once.
Or run Apple's own CPython. The stock aarch64-apple-darwin build of Python 3.13.14, on Apple's CoreFoundation, Foundation and the 141 libraries under them. It prints a SHA-256 you can check against your own Python. A 95 MB fetch and about ten seconds of interpreting — every byte of the digest travels through the emulated CPU, so one wrong bit anywhere in seventy million instructions changes the answer.

Guest output is written to this page from the emulated write syscall. The instruction count and the wall time are the emulator's own.

A dynamically linked guest is loaded the way the kernel does it: the program and its interpreter are both mapped, execution starts at the interpreter's entry, and the guest's own ld.so does the relocation — so what runs here is the real dynamic loader, not a reimplementation of one.
